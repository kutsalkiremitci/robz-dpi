<h3 align="center">Инструмент с открытым кодом для Windows и Linux: изучение и тестирование глубокой инспекции пакетов (DPI)</h3>

<p align="center">
  <b>Robz DPI</b> — сетевой инструмент, созданный для изучения того, как работают ограничения доступа,<br>
  которые провайдеры применяют с помощью глубокой инспекции пакетов (DPI), и для их проверки на собственном соединении.<br>
  Включается одной кнопкой и работает только на выбранных вами сайтах; трафик не идёт через сторонний сервер, скорость не меняется.
</p>

> [!NOTE]
> **Для обучения и тестирования.** Robz DPI — проект с открытым исходным кодом, созданный для изучения работы сетевых
> протоколов и систем DPI и для проверки этого в собственной сети. Гарантий нет; все последствия использования и
> соблюдение законов там, где вы находитесь, лежат на пользователе. Перед использованием прочитайте
> **[отказ от ответственности](DISCLAIMER.md#русский)**.

> [Об антивирусных программах](#об-антивирусных-программах).

## Назначение и рамки

Глубокая инспекция пакетов (DPI) — это когда сетевое устройство принимает решения, заглядывая внутрь проходящих
пакетов. С её помощью провайдер может прочитать имя сайта, которое в первом пакете соединения передаётся открытым
текстом, и оборвать соединение. Инструменты для изучения такого поведения существуют давно, но большинство из них
запускается из командной строки, применяется ко всем сайтам и требует технических знаний.

Цель Robz DPI — предложить те же методы в понятном, ограниченном и проверяемом виде:

- **Понятно:** одна кнопка и простой интерфейс. Не нужно править скрипты, флаги и текстовые файлы.
- **Ограниченно:** по умолчанию применяется только к выбранным вами сайтам; остальные соединения не затрагиваются.
- **Проверяемо:** весь код, обрабатывающий пакеты, находится в этом репозитории и тестируется без сети.

Robz DPI — не VPN, не прокси и не сервис доступа. Он не скрывает IP-адрес, не обеспечивает анонимность или
безопасность и не содержит списка «заблокированных сайтов»; на каких доменах он работает, решает пользователь.

## Установка

### Windows

**Требования:** 64-битная Windows 10 или Windows 11.

1. **Скачайте** [RobzDPI-Setup.exe](https://github.com/kutsalkiremitci/robz-dpi/releases/latest/download/RobzDPI-Setup.exe)
   (всегда последняя версия).
2. **Установите:** запустите файл. Установка не требует прав администратора и занимает несколько секунд.
3. **Первый запуск:** приложение один раз показывает три коротких шага: язык, согласие с отказом от ответственности
   и где оно должно работать.
4. **Включите:** нажмите большую кнопку. Windows спросит «Разрешить этому приложению вносить изменения на вашем
   устройстве?» — ответьте **Да**. Кнопка станет зелёной.

> [!IMPORTANT]
> Если на компьютере работает **GoodbyeDPI** или похожая программа, сначала закройте её. Две программы меняют один и
> тот же пакет дважды, и соединения ломаются. Robz DPI обнаруживает работающий GoodbyeDPI, предупреждает и
> останавливает его с вашего согласия.

Установщик не подписан платным сертификатом, поэтому Windows SmartScreen может показать «Система Windows защитила
ваш компьютер». Продолжить можно через **Подробнее** → **Выполнить в любом случае**. Чтобы убедиться, что файл взят
из этого репозитория, сравните его с `SHA256SUMS.txt` на странице выпуска.

**Портативная версия (без установки):** скачайте [RobzDPI-Portable.zip](https://github.com/kutsalkiremitci/robz-dpi/releases/latest/download/RobzDPI-Portable.zip), распакуйте в папку и
запустите `RobzDPI.exe`. Настройки хранятся в папке `data` рядом с ним; программа не оставляет следов на
компьютере. Чтобы удалить её, сначала удалите фоновую часть (службу Windows и драйвер) через Настройки →
**Удалить Robz DPI**, затем удалите папку. Интерфейсу нужен Microsoft Edge WebView2: он есть в Windows 11 и в
обновлённой Windows 10 (установщик добавляет его при необходимости, портативная версия — нет).

### Linux

**Требования:** 64-битный (x86_64) дистрибутив с glibc 2.35 или новее (Ubuntu 22.04, Debian 12, Fedora 36 и новее),
в котором есть systemd, nftables и polkit (есть в большинстве настольных дистрибутивов). Дополнительный драйвер не нужен: пакеты перехватывает собственная очередь пакетов ядра Linux.

| Дистрибутив | Пакет | Установка |
|---|---|---|
| Debian, Ubuntu, Linux Mint | [RobzDPI-Linux-amd64.deb](https://github.com/kutsalkiremitci/robz-dpi/releases/latest/download/RobzDPI-Linux-amd64.deb) | `sudo apt install ./RobzDPI-Linux-amd64.deb` |
| Fedora, openSUSE | [RobzDPI-Linux-x86_64.rpm](https://github.com/kutsalkiremitci/robz-dpi/releases/latest/download/RobzDPI-Linux-x86_64.rpm) | `sudo dnf install ./RobzDPI-Linux-x86_64.rpm` |
| Другие дистрибутивы (Arch, Manjaro и подобные) | [RobzDPI-Linux-x86_64.AppImage](https://github.com/kutsalkiremitci/robz-dpi/releases/latest/download/RobzDPI-Linux-x86_64.AppImage) | `chmod +x RobzDPI-Linux-x86_64.AppImage && ./RobzDPI-Linux-x86_64.AppImage` |

После установки откройте **Robz DPI** из меню приложений. При первом нажатии кнопки система попросит пароль
администратора (polkit); в системах, поддерживающих правила polkit, дальнейшие включения и выключения пароля не
требуют. Контрольные суммы пакетов находятся в `SHA256SUMS-linux.txt` на странице выпуска.

**AppImage** — один файл, не требующий установки; библиотеки, нужные интерфейсу, находятся внутри него.
Ограничения:

- Движок по-прежнему использует системные systemd, nftables и polkit; они должны быть установлены.
- Для запуска нужен FUSE 2 (Ubuntu 22.04: `sudo apt install libfuse2`; 24.04 и новее: `libfuse2t64`). Без FUSE
  можно запустить так: `./RobzDPI-Linux-x86_64.AppImage --appimage-extract-and-run`.
- Не работает в дистрибутивах на основе musl (например, Alpine).
- Если для вашего дистрибутива есть пакет `.deb` или `.rpm`, выбирайте его: он меньше, обновляется и удаляется
  менеджером пакетов.

> [!NOTE]
> Версия для Linux новая. Пакеты, которые создаёт движок, проверены автоматическими тестами, но версия проверялась
> не во всех дистрибутивах и не у всех провайдеров. Если что-то не работает,
> [сообщите](https://github.com/kutsalkiremitci/robz-dpi/issues), указав дистрибутив и приложив журнал движка.

## Использование

### Главная

- **Большая кнопка** включает и выключает движок. Когда он включён, показано, к чему он применяется и сколько
  соединений обработано.
- **Держать всегда включённым:** Robz DPI запускается в трее при старте Windows. Если движок был оставлен
  включённым, он включится сам.
- **Где должно работать?**
  - **Только выбранное** (рекомендуется): применяется только к включённым приложениям и добавленным сайтам.
  - **Все сайты:** применяется к каждому соединению. Некоторые сайты не принимают разделённое соединение и не
    открываются; добавьте их через поле **Исключить сайт**: Robz DPI не трогает их и их поддомены и работает на всех
    остальных сайтах.
- **Добавить сайт:** введите адрес (`example.com` или вставьте ссылку) и нажмите **Добавить**. Сайт появится под
  Discord и Roblox со своим переключателем; его можно временно выключить переключателем или удалить значком корзины.
  Поддомены (`cdn.example.com`) включаются автоматически; несколько адресов можно добавить сразу, разделив пробелами.
- **Проверка соединения:** пробует настоящее соединение с выбранными сайтами с этого компьютера.

Если изменить настройку при работающем движке, появится синее уведомление; новая настройка начнёт действовать после
нажатия **Применить**. Смена настроек требует подтверждения администратора; включение и выключение — нет.

### Настройки

- **Метод:** есть четыре готовых метода. Метод 1 даёт результат на большинстве соединений; если нет, пробуйте
  остальные по порядку и после каждого смотрите проверку соединения.
- **DNS:** запросы выбранных сайтов перенаправляются на указанный вами сервер (Quad9, Yandex, AdGuard, OpenDNS или
  свой). Запросы не шифруются.
- Здесь же находятся **поведение при закрытии окна**, **язык** и **удаление Robz DPI**.

### Дополнительно

После включения «Показать дополнительные настройки» появляются три раздела:

- **Подробности метода:** где делится первый пакет, порядок частей, вид и время жизни ложного запроса, сайт в ложном
  запросе, отключение QUIC и что делать, когда имя сайта не видно. При изменении настройки готового метода он
  копируется в «Свой»; готовые методы не меняются.
- **Работа движка:** число обработанных соединений, число перенаправленных DNS-запросов и последние имена сайтов.
- **Журнал движка:** когда движок запустился, с каким фильтром работает и почему остановился.

### Значок в трее

После закрытия окна Robz DPI продолжает работать из значка рядом с часами; щёлкните по нему правой кнопкой, чтобы
**включить** или **выключить** движок. Движок — отдельная служба Windows: он работает, пока вы его не выключите,
даже если полностью выйти из приложения.

### Удаление

Настройки → **Удалить Robz DPI**. Одним действием удаляются приложение, его фоновая часть (служба Windows, драйвер
WinDivert, папка `Program Files\RobzDPI`) и настройки. Фоновая часть устанавливалась с правами администратора,
поэтому Windows один раз попросит подтверждение. Удаление через список «Приложения» Windows тоже убирает фоновую
часть.

В Linux удалите пакет через менеджер пакетов (`sudo apt remove robz-dpi` или `sudo dnf remove robz-dpi`); фоновая
часть (юнит systemd, правила, `/opt/robzdpi` и `/var/lib/robzdpi`) удаляется вместе с ним. Если вы используете
AppImage, Настройки → **Удалить Robz DPI** за один шаг удаляет фоновую часть, файл AppImage и настройки; система
может один раз попросить пароль администратора. Если приложение установлено пакетом (.deb, .rpm), та же
кнопка удаляет и пакет:
приложение, фоновая часть и настройки удаляются за один шаг; система попросит пароль администратора.

## Об антивирусных программах

> [!WARNING]
> Некоторые антивирусы помечают драйвер **WinDivert**, который использует Robz DPI, как «рискованную программу»,
> помещают его файлы в карантин или не дают драйверу загрузиться. В этом случае движок не запускается или
> останавливается сам.

Этот раздел относится только к версии для Windows; версия для Linux не использует WinDivert.

В Windows Robz DPI перехватывает сетевые пакеты с помощью драйвера с открытым кодом
[WinDivert](https://github.com/basil00/WinDivert). WinDivert не является вредоносной программой; но поскольку он
может перехватывать и изменять сетевой трафик, защитные продукты относят его к «инструментам, которыми можно
злоупотребить». Такое же предупреждение появляется у всех программ, использующих WinDivert, включая GoodbyeDPI.

| Продукт | Известное поведение |
|---|---|
| **Kaspersky** | Определяет WinDivert как [`RiskTool.Multi.WinDivert.gen`](https://threats.kaspersky.com/en/threat/RiskTool.Multi.WinDivert.gen). По сообщениям пользователей, [может продолжать блокировать](https://forum.kaspersky.com/topic/exclusions-wont-work-for-goodbyedpi-52810) драйвер и после добавления исключения. |
| **Malwarebytes** | Определяет драйвер как [`RiskWare.WinDivert.VulnDriver`](https://www.malwarebytes.com/blog/detections/riskware-windivert-vulndriver). |
| **Norton** | Пользователи [сообщали](https://community.norton.com/t/i-think-norton-is-blocking-goodbyedpi/514443), что программы, использующие WinDivert, блокируются. |
| **Другие продукты** | Могут показывать похожие предупреждения; поведение зависит от продукта и версии. |

Если вы увидели такое предупреждение:

1. **Проверьте файлы.** Скачивайте установщик только со страницы
   [Releases](https://github.com/kutsalkiremitci/robz-dpi/releases) этого репозитория и сравните его с
   `SHA256SUMS.txt`. Файлы WinDivert в установщике — официальный выпуск; их суммы SHA-256 закреплены в
   [`engine.lock.json`](engine.lock.json) и проверяются и при сборке, и при установке.
2. **Добавьте исключение.** В антивирусе добавьте в исключения папку `C:\Program Files\RobzDPI` и папку, в которую
   установлено приложение, `%LOCALAPPDATA%\Robz DPI`.
3. **Восстановите файлы из карантина.** Если файлы удалены, удалите Robz DPI и установите его заново.
4. **Если блокировка продолжается,** Robz DPI нельзя использовать вместе с этим защитным продуктом.

Добавлять исключение или нет — решать вам. Прежде чем отключать предупреждение защитной программы, убедитесь, что
файлы подлинные, как описано выше.

## Устранение неполадок

<details>
<summary><b>Кнопка зелёная, но сайт не открывается</b></summary>

1. Запустите **Проверку соединения**. Если написано «Не открывается», выберите в настройках **следующий метод**,
   нажмите **Применить** и проверьте снова. Попробуйте все четыре метода.
2. Убедитесь, что включено **Перенаправлять DNS-запросы**; если да, выберите другой **DNS-сервер**.
3. Если в браузере включён «Безопасный DNS» (DoH), дело не в DNS; сосредоточьтесь на методе.
4. Если ничего не помогло, посмотрите **Работу движка** в разделе «Дополнительно». Если число соединений не растёт,
   движок не видит этот сайт (возможно, адрес добавлен неверно). Если растёт, а сайт не открывается, метод не даёт
   результата на этом соединении: [создайте issue](https://github.com/kutsalkiremitci/robz-dpi/issues), указав
   провайдера и приложив журнал движка.

</details>

<details>
<summary><b>Сообщение «Не удалось запустить движок» или «Движок остановился сам»</b></summary>

Причина указана под сообщением. Чаще всего:

- **Защитная программа заблокировала драйвер:** см. раздел
  [Об антивирусных программах](#об-антивирусных-программах).
- **Загружена несовместимая версия WinDivert:** закройте программу, которая её использует (старый GoodbyeDPI,
  zapret), и перезагрузите компьютер.
- **Windows не приняла подпись драйвера:** обновите Windows.

</details>

<details>
<summary><b>В режиме «Все сайты» некоторые сайты не открываются</b></summary>

Некоторые сайты отклоняют соединение, разделённое на две части. Это свойство самого метода, и именно поэтому
Robz DPI по умолчанию применяется только к выбранным сайтам. Вернитесь к режиму «Только выбранное» и добавьте нужные
сайты.

</details>

<details>
<summary><b>Некоторые сайты не открываются ни с одним методом</b></summary>

Robz DPI работает только с ограничениями, которые смотрят на первый пакет соединения. Если адрес закрыт провайдером
прямо на уровне IP (соединение отклоняется ещё до установления), ни один метод не даст результата.

</details>

## Как это работает

При подключении к сайту приложение сначала отправляет пакет с именем сайта (TLS ClientHello). Промежуточное
устройство DPI принимает решение, читая имя в этом пакете. Robz DPI перестраивает только этот первый пакет — так,
что сервер понимает его без труда, а промежуточное устройство не распознаёт:

1. **Делит его.** Пакет разрезается на две части, и вторая отправляется первой. Сервер расставляет части по порядку.
2. **Ставит перед ним ложный запрос.** Отправляется ложный пакет с именем другого сайта. Он либо исчезает по пути,
   не дойдя до сервера (короткое время жизни), либо испорчен так, что сервер его отбрасывает.
3. **Перенаправляет DNS-запрос.** Запрос адреса выбранного сайта уходит на указанный вами DNS-сервер; ответ
   возвращается приложению так, будто пришёл оттуда, куда оно обращалось.

Остальная часть соединения не затрагивается: скорость не падает, трафик не идёт через другой сервер.

Движок состоит из двух частей. Слой, который берёт пакеты из ядра и возвращает их, в Windows — подписанный драйвер
**WinDivert** (basil00, открытый код), а в Linux — собственная очередь пакетов ядра (nfqueue), и дополнительный
драйвер не нужен. Код, решающий, что делать с пакетом, одинаков в обеих системах и находится в этом репозитории
([`src-tauri/src/engine`](src-tauri/src/engine)):

| Файл | Назначение |
|---|---|
| `packet.rs` | Читает, делит и собирает пакеты IP, TCP и UDP; считает контрольные суммы |
| `tls.rs` | Читает имя сайта из ClientHello; создаёт ложный ClientHello |
| `dnsmsg.rs` | Читает имя в DNS-запросе и адреса в ответе |
| `logic.rs` | Решение: что делать с пакетом? (чистая логика, тестируется без сети) |
| `filter.rs` | Фильтр для драйвера: какие пакеты доходят до движка |
| `divert.rs`, `service.rs` | Windows: привязка к WinDivert и служба Windows |
| `nfqueue.rs`, `linux_service.rs` | Linux: правила nftables, очередь пакетов и юнит systemd |

## Сравнение с GoodbyeDPI

Методы Robz DPI взяты из [GoodbyeDPI](https://github.com/ValdikSS/GoodbyeDPI); движок написан с нуля на основе
изучения его исходного кода. Четыре готовых метода ведут себя как сочетания флагов из скриптов
[GoodbyeDPI-Turkey](https://github.com/cagritaskn/GoodbyeDPI-Turkey):

| Robz DPI | Аналог в GoodbyeDPI |
|---|---|
| Метод 1 | `-5 --set-ttl 5` |
| Метод 2 | `-5` |
| Метод 3 | `--set-ttl 3` |
| Метод 4 | `-9` |

Что изменилось после написания движка с нуля:

| | GoodbyeDPI | Robz DPI |
|---|---|---|
| Пакеты, доходящие до движка | Все пакеты меньше 1200 байт на порты 80 и 443 | Только первый пакет соединения; отбор происходит в драйвере |
| Перенаправление DNS | Все запросы | Только запросы выбранных сайтов (при желании все) |
| Имя сайта попало во второй пакет | В режиме списка соединение не обрабатывается | Адрес цели узнаётся из ответа DNS, и метод применяется |
| Код, читающий пакеты | C | Rust с безопасной работой с памятью; проверяется на испорченных данных |
| Автоматическое время жизни, сервер в 3 переходах | Число переполняется; ложный пакет может дойти до сервера | Исправлено |
| Что значит «работает» | Процесс запущен | Драйвер действительно открыт; если нет, сообщается причина |
| Смена настроек | Флаги командной строки, текстовый файл | Интерфейс |

GoodbyeDPI — проверенная программа, которой пользуются много лет; Robz DPI — новый проект, он проверен не у всех
провайдеров. Если один и тот же метод даёт результат в GoodbyeDPI, но не в Robz DPI, пожалуйста,
[сообщите об этом](https://github.com/kutsalkiremitci/robz-dpi/issues).

## Безопасность и конфиденциальность

- **Данные не собираются.** Нет учётной записи, рекламы, статистики и проверки обновлений. Robz DPI выходит в сеть
  только в двух случаях: к выбранным сайтам при запуске «Проверки соединения» и к выбранному DNS-серверу, пока
  включено перенаправление DNS.
- **Движок только перестраивает первый пакет.** Он не читает, не сохраняет и никуда не отправляет содержимое.
  Соединения не расшифровываются.
- **Единственный сторонний двоичный файл — WinDivert.** Он скачивается из официального выпуска; его суммы SHA-256
  закреплены в [`engine.lock.json`](engine.lock.json) и проверяются и при сборке, и при установке.
- **Права администратора запрашиваются только при необходимости.** Интерфейс работает без привилегий. Установка
  движка и смена его настроек требуют подтверждения Windows (UAC); эта работа выполняется в отдельном режиме без
  окна, и каждое значение из интерфейса проверяется заново.
- **Служба запускается из защищённой папки.** Движок копируется в `Program Files\RobzDPI`, изменять которую могут
  только администраторы. Пользователь может запускать и останавливать службу, но не может изменить запускаемую ею
  программу.
- **В Linux устройство такое же.** Движок запускается из `/opt/robzdpi` как юнит systemd, ограниченный сетевыми
  привилегиями; установка и смена настроек требуют подтверждения polkit. При остановке движка правила nftables
  удаляются.

## Частые вопросы

<details>
<summary><b>Robz DPI платный?</b></summary>

Нет. Он бесплатный и с открытым исходным кодом (MIT). Нет платной версии, рекламы и учётной записи.

</details>

<details>
<summary><b>Это VPN? Влияет ли он на скорость интернета?</b></summary>

Это не VPN. Трафик не идёт через другой сервер, IP-адрес не меняется. Robz DPI затрагивает только первый пакет
каждого соединения; остальное идёт обычным путём.

</details>

<details>
<summary><b>Работают ли голос в Discord и игра в Roblox?</b></summary>

Голосовой и игровой трафик идёт отдельным путём (UDP), и Robz DPI его не трогает. Ограничение обычно применяется при
подключении к сайту и серверам сеанса, поэтому ожидается, что после их открытия заработают и голос, и игра; но это
проверялось не на всех соединениях.

</details>

<details>
<summary><b>Какие сайты можно добавить?</b></summary>

Любые. В Robz DPI нет списка сайтов; Discord и Roblox — лишь готовые ярлыки.

</details>

<details>
<summary><b>Это законно?</b></summary>

Это зависит от страны, в которой вы находитесь, и от того, для чего вы используете программу; этот репозиторий не
даёт юридических консультаций. Robz DPI — сетевой инструмент для обучения и тестирования: за то, как и где он
используется, отвечает пользователь. Знать и соблюдать законы, решения судов и органов власти там, где вы
находитесь, — ваша обязанность. Если сомневаетесь, не используйте его и обратитесь к юристу. Подробнее:
[отказ от ответственности](DISCLAIMER.md#русский).

</details>

## Разработка

**Требуется:** [Rust](https://rustup.rs) (MSVC), Node.js 22+, инструменты C++ из Visual Studio и Windows SDK
([предварительные требования Tauri для Windows](https://tauri.app/start/prerequisites/)). В Linux:
`libwebkit2gtk-4.1-dev`, `libayatana-appindicator3-dev`, `librsvg2-dev`, `libxdo-dev`, `libssl-dev`.

```powershell
npm install          # копирует библиотеки интерфейса, скачивает и проверяет WinDivert
npm run dev          # запуск в режиме разработки
npm test             # тесты интерфейса (node --test) и движка (cargo test)
npm run build        # установщик для Windows: src-tauri/target/release/bundle/nsis/
npm run build:linux  # Linux: сначала программа движка (robzdpi-engine), затем deb, rpm и AppImage
```

- **Движок тестируется без сети.** `logic.rs` — чистая логика: тесты подают вручную собранные пакеты и проверяют
  выходящие (порядок, место разделения, время жизни, контрольную сумму). Фильтры компилируются настоящим
  `WinDivert.dll` и применяются к примерам пакетов; драйвер не загружается. Пакет для Linux устанавливается в CI и
  проверяется целиком скриптом [`scripts/linux-smoke.sh`](scripts/linux-smoke.sh): движок ставится с настоящими
  systemd и nftables, через него открывается сайт, затем движок удаляется.
- **Интерфейс можно открыть в браузере.** Если открыть папку `ui/` любым локальным сервером
  (`python -m http.server --directory ui`), вместо настоящего ядра подключится имитация
  ([`ui/js/dev-mock.js`](ui/js/dev-mock.js)).
- `node scripts/screenshots.mjs` заново создаёт снимки в [`docs/screenshots`](docs/screenshots) на трёх языках,
  `node scripts/render-banners.mjs` — изображения для README, `node site/build.mjs` — сайт.

**Выпуск версии:** укажите одинаковый номер версии в `package.json`, `src-tauri/Cargo.toml` и
`src-tauri/tauri.conf.json`, запишите заметки в [`CHANGELOG.md`](CHANGELOG.md) и отправьте тег `vX.Y.Z`.
